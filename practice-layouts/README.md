# Practice Layouts — HTML/CSS/JS

10 self-contained layouts to sharpen your front-end skills, from simple to interactive.
Each folder has its own index.html (open it directly in your browser, or use Live Server / Live Preview in Antigravity).

## Order to practice in

1. 01-profile-card — box model, flexbox centering, shadows
2. 02-pricing-table — flexbox rows, hover states, highlighting one item
3. 03-navbar-dropdown — flexbox, position:relative/absolute, click events
4. 04-image-gallery — CSS grid, auto-fit/minmax, responsive images
5. 05-landing-page — combining flexbox + grid, spacing rhythm, gradients
6. 06-dashboard-sidebar — app-like layout, media queries, JS toggle for mobile menu
7. 07-tabs — JS DOM manipulation, classList, data attributes
8. 08-accordion — JS + CSS transitions, max-height animation trick
9. 09-modal — position:fixed, z-index, click-outside-to-close logic
10. 10-sticky-header — scroll event listener, dynamic class toggling

## How to use them

- Just open any index.html in your browser to see it working.
- Better: install "Live Server" (Ritwick Dey) in Antigravity, right-click index.html > "Open with Live Server" for auto-refresh as you edit.
- Try rebuilding each one from scratch yourself before peeking at the code, then compare your version to this one.
- Once comfortable, try rebuilding #7, #8, #9 as React components using useState instead of vanilla JS.

Have fun breaking and rebuilding these!
